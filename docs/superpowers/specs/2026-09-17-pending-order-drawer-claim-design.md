# 待接单详情抽屉内接单

## 目标

仓储人员打开「待接单」订单详情后，可直接在侧边抽屉内完成接单，无需关闭抽屉返回列表。

## 交互

1. 订单状态为 `10`（待接单）时，抽屉底部显示主按钮「接单」。
2. 点击后打开仓库选择弹窗，加载现有仓库下拉选项。
3. 选择仓库并确认后，调用既有 `POST /api/warehouse/orders/{id}/claim`。
4. 成功后关闭选择弹窗、刷新当前详情为 `20`（已接单）、通知列表刷新；用户可立即在同一抽屉中处理货号。
5. 非待接单状态不显示该按钮，避免重复接单或非法状态流转。

## 组件边界

- `WarehouseOrderDetailDrawer.vue`：承载抽屉内接单按钮、仓库选择弹窗、提交状态与详情刷新。
- 既有 `claimOrder`、`getWarehouseOptions` API：复用，不新增接口或后端改动。
- 父页面 `PendingOrders.vue`：继续保留列表行的现有接单入口；只消费抽屉的 `updated` 事件刷新列表。

## 错误处理与验收

- 仓库未选择时阻止提交并提示。
- 请求失败由现有请求拦截器展示后端业务错误；按钮恢复可点击状态。
- 成功后抽屉显示接单人及可用的货号关联操作，列表不再显示该订单。
- 通过前端构建校验，并手动验证待接单详情页内的完整接单流程。
