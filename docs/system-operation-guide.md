# 仓储管理系统操作逻辑

## 角色与入口

| 角色 | 主要入口 | 主要职责 |
| --- | --- | --- |
| 运营 | 我的订单、新建订单、货号查询 | 创建订单、查看发货结果、确认完成 |
| 仓储 | 订单处理、备货发货、货号库存 | 关联货号、备货采购、发货回传、维护库存 |
| 管理员 | 全部模块 | 查看全量数据、维护基础资料与库存 |

系统里“货号”是原先 SKU 的统一业务名称。底层字段仍沿用 `sku_id`，不影响历史数据。

## 日常订单流程

### 1. 运营创建订单

1. 在“新建订单”填写订单号和备注。
2. 填写一个或多个商品明细：商品名、数量、预计成本。
3. 已有商品可填写货号；没有货号时勾选新商品，由仓储后续关联或新建货号。
4. 提交后订单进入“待接单”。

### 2. 仓储接单并关联货号

1. 在“订单处理”查看全部订单，可按订单号、商品名、备注和状态查询。
2. 对“待接单”订单点击接单。
3. 打开订单详情，为每一条商品明细选择已有货号，或新建货号后关联。
4. 所有明细完成关联后，订单进入“数量待确认”。

货号自动按照三级分类生成，例如 `A001-B001-C001`：

- `A001`：一级分类；
- `B001`：二级分类；
- `C001`：三级分类或具体规格。

### 3. 运营确认数量

运营在“我的订单”确认最终数量。确认后订单进入“备货中”，仓储可以开始备货、采购或发货。

### 4. 仓储备货、采购与发货

1. “备货发货”默认展示备货订单。
2. 系统优先标记库存能够完整满足的订单，缺货订单不会阻塞后续可完整发货的订单。
3. 需要补货时切换到“采购汇总”，按货号汇总待备数量、可用库存和建议采购量。
4. 采购到货或提前备货时，在“货号库存”点击“采购入库”，选择货号、仓库和数量，库存即时增加并生成流水。
5. 货齐后在备货订单中发货，填写物流单号和实际发货数量；库存即时扣减并生成出库记录。

### 5. 运营查看结果并完成订单

仓储发货后，运营可在订单详情查看每次发货的货号、数量、物流单号和时间。全部发完后，运营确认完成。

## 仓储端页面说明

### 订单处理

用于查看全部订单、按条件查询、接单，以及为订单明细关联或新建货号。

### 备货发货

页面顶部可以切换：

- **备货订单**：查看可优先发货和缺货待采购的订单，并执行发货；
- **采购汇总**：按仓库和货号汇总订单需求与安全库存，得到建议采购量；
- **出库记录**：查看已发货的出库单和物流信息。

### 货号库存

页面顶部可以切换：

- **货号库存**：查询库存、自动生成货号、采购入库、调整库存、查看库存流水、启用或停用货号；
- **库存预警**：查看可用库存低于安全库存的货号，并显示短缺量。

新生成但尚未入库的货号，也会在库存预警中显示为“未入库”。

## 库存与预警规则

- 可用库存 = 库存数量 - 预留数量。
- 新货号的默认安全库存为 **10**。
- 可用库存低于安全库存时，出现在“库存预警”。
- 建议采购量按照订单待备数量和安全库存的较大值计算，再扣减可用库存。
- 停用货号后，不能再关联新订单，也不能采购入库；历史订单、出库和库存流水仍可查询。

## 关键原则

- 一个订单可包含多个商品明细；每个明细最终关联一个具体货号。
- 一个货号只代表一个明确商品规格，不包含仓库或库位。
- 库存按“仓库 + 货号”管理。
- 订单发货扣库存；采购入库和手工调整会写入库存流水，方便追踪数量变化。
